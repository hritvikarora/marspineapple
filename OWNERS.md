# Folder ownership

One owner per folder. Edit someone else's folder only after agreeing with them; shared contracts change
only through Role C (see INTERFACE.md §9).

| Path | Owner | Notes |
|---|---|---|
| `src/contracts/` | **Role C** | Canonical types + shared coordinate adapter (`grid.ts`). Changes need team sign-off. |
| `src/state/` | **Role C** | Store, invalidation rules, `useRouteRunner` glue. |
| `src/data/` | **Role C** | `loadAndValidateBundle`. |
| `src/app/` | **Role C** | Composition: bundle selection, region loader, 3D slot (WebGL probe + error boundary + lazy load), optional tile adapter. |
| `src/export/` | **Role C** | Deterministic JSON export. |
| `src/worker/client.ts`, `src/worker/handler.ts`, `src/worker/routing.worker.ts` | **Role C** (protocol) | Ayush owns what runs inside `solveRoute`. |
| `src/routing/` | **Ayush** | Solver, model profile, metrics, explanations, worker internals. `placeholderEngine.ts` is a stub to replace. |
| `src/ui/` | **Dhani** | Mission workflow, map, comparison, briefing. `App.tsx`/`MapCanvas.tsx` are minimal stubs. |
| `src/terrain3d/` | **Role B** | Three.js terrain; keep `TerrainViewProps` (or renegotiate). |
| `public/bundles/` | **Role A** | Versioned region bundles. `synthetic-v0` is generated by Role C's script; don't hand-edit. |
| `scripts/` (data processing, e.g. `scripts/data/`) | **Role A** | Python/GDAL preprocessing + its config. |
| `scripts/make-fixture.mjs`, `scripts/validate-bundle.mjs`, `scripts/smoke-preview.mjs`, `scripts/audit.mjs` | **Role C** | |
| `public/bundles/index.json` | **Role A** edits `release`; Role C reviews | Which bundle production serves. |
| `tests/` | **Role C** (integration) | Specialist tests live next to their code (e.g. `src/routing/*.test.ts`). |
| `src/config.ts`, `vite.config.ts`, `package.json`, `README.md`, `INTERFACE.md`, deploy | **Role C** | |
